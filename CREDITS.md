# Credits

serrebiALT is the AltStore source for serrebidev's iOS apps. In AltStore, open Sources, tap Add, and paste the apps.json address from the README. Publishing an app version builds the .ipa (needs macOS) and runs `python add_app.py` with a Forgejo token.

AltStore is a third-party sideloading tool. This repository is only the source file it reads.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
